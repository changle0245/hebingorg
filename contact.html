常见问题

为什么我没有收到回复？
99% 邮件 48 小时内回复。如超过 5 天未回复，请检查垃圾邮件文件夹。
能不能加微信/QQ？
目前我们只通过邮件沟通。原因：邮件可以集中处理、保持记录。
能否转载博客？
可以。请注明原文链接和作者 hebing.org，不要大幅删改。
企业能否私有化部署？
可以。发邮件主题加 [Business]，我们会安排详细沟通。
能否提供 API？
目前所有工具都是浏览器内运行，没有 HTTP API。如有真实需求可邮件告知。
发现安全漏洞如何报告？
邮件主题加 [Security]，请勿在公开渠道讨论未修复漏洞。

FAQ

Why haven't I received a reply?
99% of emails get replies within 48 hours. If 5+ days, check spam folder.
Can we add WeChat/messaging?
We use only email. Lets us batch responses, keep records, avoid disruption.
Can I republish blog posts?
Yes. Credit original URL and author hebing.org; don't drastically alter.
Enterprise on-premise deployment?
Yes. Email with [Business] subject, we'll arrange detailed discussion.
API available?
Tools run in browser; no HTTP API currently. If you have real needs, email us.
Security vulnerability report?
Email with [Security] subject; do NOT discuss unfixed issues publicly.
