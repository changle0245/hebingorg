格式选择指南

  • JPG：兼容性最好，文件中等。适合照片、社交媒体、不需要透明的场景。
  • PNG：无损 + 支持透明背景。适合截图、Logo、设计稿，但体积较大。
  • WebP：比 JPG 小约 30%，支持透明，现代浏览器全部兼容。网站优化首选。
  • AVIF：比 WebP 再小 20–30%，但浏览器支持较新（Chrome 85+ / Safari 16.4+）。追求极小体积时使用。
  • JPG: best compatibility, medium size. Photos, social media, anything without transparency.
  • PNG: lossless with transparency. Screenshots, logos, design assets — but larger file size.
  • WebP: ~30% smaller than JPG, supports transparency, universal modern-browser support. Top pick for web.
  • AVIF: ~20–30% smaller than WebP, but newer (Chrome 85+ / Safari 16.4+). Use when minimum size matters most.
  • JPG: أفضل توافق، حجم متوسط. الصور ووسائل التواصل وأي شيء بدون شفافية.
  • PNG: بدون فقد مع شفافية. لقطات الشاشة والشعارات وأصول التصميم — لكن حجم ملف أكبر.
  • WebP: ~30٪ أصغر من JPG، يدعم الشفافية، دعم شامل للمتصفحات الحديثة. الخيار الأول للويب.
  • AVIF: ~20-30٪ أصغر من WebP، لكنه أحدث (Chrome 85+ / Safari 16.4+). استخدمه عندما يكون الحجم الأدنى الأهم.
常见问题
PNG 转 JPG 后透明背景会怎样？
JPG 不支持透明通道，转换时透明区域会被自动叠加为白色背景。如果需要保留透明效果，请选择 PNG 或 WebP 作为目标格式。
WebP 和 AVIF 哪个更小？
通常 AVIF 比 WebP 再小 20–30%，但兼容性较差（需要 Chrome 85+ / Safari 16.4+）。WebP 是更稳妥的网络分发选择，AVIF 适合现代浏览器优先的场景。
支持 HEIC（苹果照片）吗？
目前仅支持浏览器原生可解码的格式（JPG / PNG / WebP / AVIF / GIF / BMP）。HEIC 在多数浏览器需要专门解码器，本工具暂不支持，建议先在系统照片应用中导出为 JPG。
文件会上传到服务器吗？
不会。所有处理在浏览器本地完成（Canvas API + canvas.toBlob），图片文件不离开你的设备。
