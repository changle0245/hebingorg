关于 hebing.org

hebing.org 是一个完全免费、不上传文件、不需注册的在线文件处理工具集合。截至 2026 年，我们提供 30 款覆盖文件合并、格式转换、图片处理、PDF 编辑与开发者实用工具，全部在浏览器本地运行。

这个项目从一个非常具体的需求开始：2023 年，我们发现身边的同事、朋友、客户都在反复使用各种"在线工具"处理文件——而这些工具几乎都把文件上传到陌生服务器、塞满广告、或者偷偷限制免费版的功能。我们决定做一个反向的产品：所有处理在浏览器内完成、文件永不离开设备、永久免费、没有任何使用次数限制。

技术架构：为什么能做到本地处理

过去十年浏览器的能力发生了革命性变化。今天，下面这些操作都可以在浏览器内完成，不需要任何后端服务器：

  • PDF 合并、拆分、加密——使用 pdf-lib 和 PDF.js（Mozilla 开源）；
  • Excel/Word/PPT 处理——使用 SheetJS、docx、PptxGenJS 在浏览器内解析 Office Open XML；
  • 图片压缩与格式转换——使用 Canvas API 和 WebAssembly 编译的图像编码器；
  • 音频/视频合并——使用 FFmpeg.wasm（FFmpeg 编译为 WebAssembly）；
  • 密码学操作（Hash、JWT）——使用浏览器原生的 Web Crypto API；
  • JSON/XML/正则——使用 JavaScript 内置的解析器和 RegExp 引擎。

这意味着：你可以拔掉网线，所有工具仍能完整工作。我们的网站使用 Service Worker 缓存所有资源，第二次访问甚至不需要联网。

不会。本站从立项第一天就承诺永久免费，这是我们对用户的核心承诺。如果有商业模式调整，会在网站显著位置提前公告，并且永远保留免费版本。

Technical Architecture: How Local Processing Works

Browser capabilities have transformed in the last decade. All these can run in-browser without any backend:

  • PDF merge, split, encrypt — pdf-lib and PDF.js (Mozilla open source);
  • Excel/Word/PPT processing — SheetJS, docx, PptxGenJS for parsing Office Open XML;
  • Image compression and conversion — Canvas API and WebAssembly-compiled image codecs;
  • Audio/video merging — FFmpeg.wasm (FFmpeg compiled to WebAssembly);
  • Cryptography (Hash, JWT) — native Web Crypto API;
  • JSON/XML/regex — JavaScript built-in parsers and RegExp engine.

This means: you can disconnect from the internet and all tools still work fully. Our site uses Service Worker caching, so second visits don't even need network.
