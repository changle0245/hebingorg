使用技巧

  • 水印中文支持：使用 mupdf 内置 CJK 字体，中文 / 日文 / 韩文均可直接渲染，不需要嵌入字体。
  • 旋转与「视觉旋转」的区别：本工具改 PDF 的 /Rotate 页面元数据，等价于 Acrobat 的「旋转视图 → 保存」，所有阅读器都尊重它。
  • 重排支持的操作：拖拽换位、点 ✕ 删除、点 +1 复制一份在原位之后、整体反转、重置回原序。
  • 加密 PDF：先到 PDF 加密 / 解密 移除密码再来编辑。
  • 大文件：mupdf 加载约 3.4 MB（首次），之后缓存复用。500 页内的 PDF 在 5s 内完成。
  • CJK watermark: mupdf has built-in CJK fonts — Chinese / Japanese / Korean text renders directly, no font embedding.
  • Rotation vs visual rotation: this tool sets page /Rotate metadata (same as Acrobat's "rotate view → save"); all readers honor it.
  • Reorder supports: drag-swap, ✕ to delete, +1 to duplicate after, reverse all, reset to original.
  • Encrypted PDFs: strip password at PDF Encrypt/Decrypt first.
  • Big files: mupdf loads once (~3.4 MB Brotli), cached after. 500-page PDFs finish under 5s.
  • علامة مائية CJK: يحتوي mupdf على خطوط CJK مدمجة — تظهر النصوص الصينية / اليابانية / الكورية مباشرة، بدون تضمين خط.
  • الدوران مقابل الدوران المرئي: تضبط هذه الأداة بيانات الصفحة /Rotate (نفس "rotate view → save" في Acrobat)؛ جميع القارئين يحترمونها.
  • إعادة الترتيب تدعم: السحب-التبديل، ✕ للحذف، +1 للتكرار بعد، عكس الكل، إعادة تعيين إلى الأصلي.
  • PDFs المشفَّرة: جرّد كلمة المرور في PDF Encrypt/Decrypt أولاً.
  • الملفات الكبيرة: يحمَّل mupdf مرة واحدة (~3.4 ميجابايت Brotli)، مخزن مؤقتاً بعد ذلك. PDFs بـ 500 صفحة تنتهي تحت 5 ثوانٍ.
常见问题
水印会不会破坏 PDF 原内容？
不会。水印写在每页内容流末尾，是独立的文本绘制操作。原页面文字、图片、表单字段、链接全部保留。
旋转后又恢复了？
本工具改 /Rotate 元数据（与 Acrobat 旋转一致），所有现代阅读器都尊重它。
拖拽重排后能撤销吗？
点「重置」恢复原始顺序；切到其他模式再切回也会重新加载。处理后下载的是新文件，原文件不变。
加密 PDF 能编辑吗？
先到 PDF 加密 / 解密 工具输入密码移除保护后再来此页编辑。
